# Index Templates

New index templates for recommender-specific indices. These do not modify esdiag's existing templates.

**Status**: Not yet built.

## Planned templates

| Template | Index Pattern | Purpose |
|----------|--------------|---------|
| `recommender-findings` | `recommender-findings-*` | Agent findings and recommendations |
| `recommender-projections` | `recommender-projections-*` | Capacity and cost projection outputs |
| `recommender-customer-context` | `recommender-customer-context-*` | Customer notes and conversation history |
| `recommender-reports` | `recommender-reports-*` | Generated advisory report documents |

## Deployment requirement

Cluster-level access required. Coordinate with esdiag repo owner before deploying.
